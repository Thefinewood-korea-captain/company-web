# 더조은목재 홈페이지 (company-web)

주식회사 더조은목재 홈페이지입니다. AI(Claude)로 만들고 유지관리합니다.

| 위치 | 내용 |
|---|---|
| `index.html` | **지금 쓰는 홈페이지** (주소로 열면 이 파일이 뜹니다) |
| `1단계_홈페이지/` | 1단계 때 모습 그대로 보관 |

- 장바구니·결제·단가표는 기존 쇼핑몰(https://thefinewood.co.kr)을 그대로 사용합니다.
- 매입가·매입처가 들어 있는 상품관리(ERP) 자료는 이 저장소에 올리지 않습니다 (`.gitignore`로 제외).
